Comment mettre à jour les scores

Les scores affichés sont une auto-évaluation argumentée (v2, 12/07/2026), fondée sur les activités documentées du dossier et la présentation de soutenance v3 ; la Grille 4 (/70) reste à 0 car elle est attribuée par le jury (dossier, présentation, entretien).

Le tableau de bord lit ses scores depuis le dictionnaire LIVRABLES défini en tête du fichier dashboards/grille-efs.qmd. Pour mettre à jour :

  1. Ouvrir dashboards/grille-efs.qmd
  2. Modifier les valeurs obtenu dans la section LIVRABLES = {...}
  3. Re-build : quarto render (ou push si workflow GitHub Actions actif)

Le score global, les barres de progression, les valueboxes et le tableau se recalculent automatiquement.
