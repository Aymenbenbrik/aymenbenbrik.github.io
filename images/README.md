# Images du site

Fichiers à déposer dans ce dossier :

- `logo.png` — logo Esprit School of Business (navbar) — hauteur ~36 px
- `favicon.png` — favicon 32×32 ou 64×64 px
- `photo.jpg` — photo de profil (page d'accueil) — carrée recommandée, ≥ 400×400 px

Si un fichier manque, Quarto affichera un placeholder ; le site se compile quand même.
